Projects

Each folder under the projects folder syncs with the SP project of the same name. Folders and projects that are excluded are ignored on both sides.

Changing this points existing folders at the new name. Rename the files in the vault to match.

Off: a deleted folder is created again on the next sync. On: nothing is removed without your answer.

Off: the tag has no effect. On: a task with #ignore is not created, updated or deleted on either side.

Off: the folder is offered again as a new project. On: the folder is left out of sync from then on.
